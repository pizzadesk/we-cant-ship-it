WE CANT SHIP IT -- Custom Card Creator Pack
==============================================

You have been given this pack to design Feature Cards for WE CANT SHIP IT.
 Cards you make can be sent back to the developer and added to the game.


WHAT YOU NEED
-------------
  A plain text editor -- one of these works perfectly:
    Windows : Notepad  (already on your computer)
    Mac     : TextEdit (already on your computer -- see Mac note below)
    Linux   : gedit, mousepad, kate, or similar

  !! Do NOT use Microsoft Word, LibreOffice Writer, or Google Docs.
     They add hidden formatting that breaks the file.

  Mac / TextEdit note:
    TextEdit defaults to rich text mode. Before editing any file, go to:
    Format -> Make Plain Text


WHAT IS IN THIS FOLDER
-----------------------
  card_template.tres                  <-- Copy this. Do NOT edit the original.
  example_photo_mode_challenge.tres   <-- A finished card. Open it to learn.
  TUTORIAL.txt                        <-- Step-by-step guide. Start here.
  README.txt                          <-- This file.


WHAT YOU ARE MAKING
--------------------
  A Feature Card is one of the ideas your in-game studio can add to
  their game. Each card has:

    A name            -- what shows up in-game
    An ambition value -- how much scope/boldness the feature adds (1-10)
    An instability value -- how much chaos/jank it causes (1-10)
    Tags              -- what type of feature it is (affects interactions)

  Cards can be anything: systems, mechanics, marketing stunts, bad ideas,
  great ideas, or things that only make sense at 2am during crunch.


HOW TO SUBMIT
--------------
  When your card is ready, send your .tres file to the developer.
  You can include your name in the card's feature_name if you like.


QUICK RULES
-----------
  OK  Always copy the template -- never edit card_template.tres directly
  OK  Rename your copy  (example: my_water_physics.tres)
  NO  Do not include the word "template" in your filename
  NO  Do not use Word, Google Docs, or any rich-text editor
  NO  Do not change or delete the first 5 lines of the file
  NO  Do not leave feature_name empty
  NO  Do not leave tags empty -- at least one tag is required


IF SOMETHING LOOKS WRONG
-------------------------
  Open your file and example_photo_mode_challenge.tres side by side
  in Notepad. The structure must be identical -- only the values differ.
  Read TUTORIAL.txt for detailed troubleshooting.
